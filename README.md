A farmer-focused digital platform concept connecting **farmers, agricultural markets, and agri-retailers**.

🌐 **Demo:** https://pavanwadile77.github.io/Agri-Link/

## ✨ Core Features
- Digital farmer identity and QR profile
- Farm and crop information
- Mandi / APMC price information
- Location, crop and market search
- Price trend visualization
- Retailer discovery and requirement matching

## 🛠️ Tech Stack
**React Native · Expo · React Navigation · Redux Toolkit · SVG · Lucide React Native · Recharts / Victory Native**

## ▶️ Run Locally
```bash
git clone https://github.com/PavanWadile77/Agri-Link.git
cd Agri-Link
npm install
npx expo start
```
